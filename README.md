# AI Resume Analyzer

## Overview

AI Resume Analyzer is a simple web application that analyzes resumes using Artificial Intelligence. Users can upload a PDF resume, and the application provides an estimated ATS score, resume summary, detected skills, strengths, weaknesses, and suggestions for improvement.

The main objective of this project is to help users understand how well their resume is prepared for job applications.

---

## Features

- Upload resume in PDF format
- AI-generated resume summary
- Estimated ATS score
- Skills detection
- Strengths and weaknesses analysis
- Resume improvement suggestions
- Clean and responsive user interface
